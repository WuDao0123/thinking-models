# 12 学习与认知

适用于学新技能、知识管理、教学、专业成长。

### 费曼技巧 Feynman Technique
- 核心：用简单语言教给外行，讲不清楚的地方就是没懂的地方。
- 适用信号：检验理解、学习新概念、写解释性内容。
- 使用步骤：①选概念 ②假装教给 12 岁孩子 ③找出卡壳或依赖术语的地方 ④回到资料补漏 ⑤简化并用类比重讲。
- 常见误区：简化到失真。

### 间隔重复 Spaced Repetition
- 核心：在快要遗忘时复习，间隔逐渐拉长，记忆效率最高。
- 适用信号：需要长期记住的知识（语言、术语、考试）。
- 使用步骤：①制作卡片 ②按 1 天、3 天、7 天、14 天、30 天…复习 ③使用 Anki 等工具 ④记不住的缩短间隔。
- 常见误区：用于需要理解而非记忆的内容。

### 主动回忆 Active Recall
- 核心：主动从记忆中提取比重复阅读更有效。
- 适用信号：学习效率低、读了就忘。
- 使用步骤：①读完合上书 ②写下或说出要点 ③对照补漏 ④用自测题代替重读。
- 常见误区：把画重点当学习。

### 交错练习 Interleaving
- 核心：混合练习不同类型的问题，比集中练一种效果更好。
- 适用信号：技能练习、解题能力、运动训练。
- 使用步骤：①把不同类型题目混合 ②强迫自己识别"这是哪类问题" ③接受短期表现下降。
- 常见误区：初学阶段过早交错。

### 刻意练习 Deliberate Practice
- 核心：在舒适区边缘，针对明确弱点，有即时反馈地专注练习。
- 适用信号：技能停滞、想从业余到专业。
- 使用步骤：①拆解技能为子技能 ②找最弱环节 ③设定具体可测目标 ④获得即时反馈（教练、录像、数据） ⑤反复调整。
- 常见误区：把重复劳动当练习。

### 布鲁姆分类法 Bloom's Taxonomy
- 核心：认知层级：记忆 → 理解 → 应用 → 分析 → 评价 → 创造。
- 适用信号：设计课程、检验学习深度、出题。
- 使用步骤：①定位当前掌握层级 ②设计更高层级的练习任务 ③用对应动词设定学习目标。
- 常见误区：只停留在记忆层。

### T 型人才 T-Shaped Skills
- 核心：一个领域深度 + 多领域广度（可扩展为 π 型、梳型）。
- 适用信号：职业规划、技能组合选择。
- 使用步骤：①确定纵向深耕领域 ②选择能与之协同的横向领域 ③寻找交叉点形成独特组合。
- 常见误区：广而不深。

### 技能叠加 Skill Stacking / Talent Stack
- 核心：斯科特·亚当斯——多项前 25% 的技能组合，比单项前 1% 更容易获得且更稀缺。
- 适用信号：个人竞争力、职业差异化。
- 使用步骤：①列出已有技能 ②找互补且市场看重的技能 ③学到"够好" ④组合成独特定位。
- 常见误区：技能组合没有市场需求。

### 卡片盒笔记法 Zettelkasten
- 核心：原子化笔记 + 互相链接，让想法在网络中产生新连接。
- 适用信号：知识管理、写作素材积累、研究。
- 使用步骤：①阅读时记录文献笔记 ②用自己的话写永久笔记（一条一观点） ③与已有笔记建立链接 ④从笔记网络中生成文章。
- 常见误区：收集多、加工少。

### 合意困难 Desirable Difficulties
- 核心：适度增加学习难度（测试、间隔、交错、生成）提升长期保持。
- 适用信号：学得顺利但记不住。
- 使用步骤：①把复习改为测试 ②先尝试回答再看答案 ③变化学习情境。
- 常见误区：难度过高导致放弃。

### 组块化 Chunking
- 核心：把信息组合成有意义的单元，突破工作记忆限制。
- 适用信号：复杂技能学习、记忆大量信息、内容组织。
- 使用步骤：①识别信息间的模式 ②组合成块 ③反复练习直到块自动化 ④用块构建更大的块。
- 常见误区：没有理解就硬组块。

### 德雷福斯技能模型 Dreyfus Model
- 核心：新手 → 高级初学者 → 胜任者 → 精通者 → 专家，各阶段需求不同。
- 适用信号：判断学习阶段、设计培训、带新人。
- 使用步骤：①定位阶段 ②新手给规则和清单 ③胜任者给目标和自主 ④专家给复杂情境和直觉空间。
- 常见误区：对新手给原则、对专家给规则。

### 元认知 Metacognition
- 核心：对自己思维过程的觉察和调控。
- 适用信号：学习方法无效、思维盲区。
- 使用步骤：①计划：我要学什么、怎么学 ②监控：我理解了吗 ③评估：方法有效吗 ④调整策略。
- 常见误区：只学内容不反思方法。

### 学习迁移 Transfer of Learning
- 核心：把在一个情境学到的知识应用到新情境。
- 适用信号：跨领域应用、学了用不上。
- 使用步骤：①提炼抽象原理 ②在多个不同情境中练习 ③主动寻找类比。
- 常见误区：期待自动迁移。

### 库伯学习圈 Kolb's Learning Cycle
- 核心：具体体验 → 反思观察 → 抽象概括 → 主动实践。
- 适用信号：从经验中学习、复盘、培训设计。
- 使用步骤：①描述经历 ②反思发生了什么、为什么 ③提炼原则 ④设计下次实验。
- 常见误区：只有体验没有反思。

### 超级学习 Ultralearning
- 核心：斯科特·杨——元学习、专注、直接实践、钻研、提取、反馈、保持、直觉、实验九原则。
- 适用信号：短期高强度掌握一项技能。
- 使用步骤：①研究如何学（元学习）②直接在目标情境练习 ③专攻弱点 ④持续测试与反馈。
- 常见误区：忽视直接实践。

### 二八学习法 80/20 Learning
- 核心：找出产生 80% 效果的 20% 核心知识先学。
- 适用信号：快速入门、时间有限。
- 使用步骤：①问专家或看高频内容找核心 20% ②集中学习 ③用实践检验 ④再按需深入。
- 常见误区：永远停在入门。

### 复盘 After Action Review
- 核心：目标是什么 → 实际发生了什么 → 差异原因 → 下次怎么做。
- 适用信号：项目结束、失败后、阶段总结。
- 使用步骤：①回顾目标 ②还原事实 ③分析差异原因（区分可控与运气） ④提炼可执行改进 ⑤落到清单或流程。
- 常见误区：变成追责会；只总结不改变。

### 生成效应 Generation Effect
- 核心：自己生成的信息比被动接收的记得更牢。
- 适用信号：学习、教学设计。
- 使用步骤：①先预测答案再学 ②用自己的话总结 ③制作自己的例子。
- 常见误区：直接看答案。

### 心智模型构建 Schema Building
- 核心：专家拥有组织良好的知识框架，新知识挂到框架上才能被理解。
- 适用信号：学新领域感到碎片化。
- 使用步骤：①先建立领域全景地图（核心概念、关系） ②学细节时挂到地图上 ③定期重构地图。
- 常见误区：一开始就陷入细节。
