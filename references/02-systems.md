# 02 系统思维

适用于"问题反复出现""越治越糟""牵一发动全身"的情形。核心是看结构而不是看事件。

### 反馈回路 Feedback Loops
- 核心：增强回路（越来越多/越来越少）与调节回路（趋向目标）共同决定系统行为。
- 适用信号：增长失控或停滞；"越…越…"的现象；指标反复震荡。
- 使用步骤：①列出关键变量 ②画因果箭头并标正/负 ③识别闭环：同向为增强，反向为调节 ④判断当前哪个回路主导 ⑤找能加强好回路、削弱坏回路的干预点。
- 常见误区：只看单向因果；忽略回路之间的切换。

### 存量与流量 Stocks and Flows
- 核心：存量（用户数、现金、信任）只能通过流入和流出改变，有惯性。
- 适用信号：用户增长、现金流、库存、人才流失、声誉积累。
- 使用步骤：①识别关键存量 ②列出所有流入和流出 ③量化各流速 ④判断改流入还是改流出更便宜（往往堵漏比开源划算） ⑤估算存量达到目标所需时间。
- 常见误区：只盯流入（拉新）不看流出（流失）。

### 杠杆点 Leverage Points
- 核心：梅多斯 12 个干预点，从弱到强：参数 < 缓冲 < 结构 < 延迟 < 回路 < 信息流 < 规则 < 自组织 < 目标 < 范式。
- 适用信号：想用最小力气改变系统；调参数总是没效果。
- 使用步骤：①列出你正在尝试的干预 ②对照层级定位 ③向上寻找更高层干预（改信息流、规则、目标） ④评估可行性后选择。
- 常见误区：高杠杆点往往反直觉、阻力大，要准备好对抗。

### 涌现 Emergence
- 核心：整体表现出个体不具备的属性，无法通过拆解部件预测。
- 适用信号：文化、市场、社区氛围、生态；"每个人都没错但整体糟了"。
- 使用步骤：①识别个体层面的简单规则 ②观察互动方式 ③通过调整规则和互动（而非直接控制结果）引导整体 ④小范围试验观察涌现结果。
- 常见误区：试图自上而下直接命令出涌现结果。

### 约束理论 / 瓶颈 Theory of Constraints
- 核心：系统产出由最弱环节决定，优化非瓶颈环节是浪费。
- 适用信号：流程慢、产能不足、增长卡住、团队忙但产出低。
- 使用步骤：①识别瓶颈（堆积/等待最多的环节） ②充分利用瓶颈（不让它闲置） ③其他环节服从瓶颈节奏 ④提升瓶颈能力 ⑤瓶颈转移后重复。
- 常见误区：同时优化所有环节；瓶颈移动后不重新识别。

### 延迟 Delays
- 核心：因果之间的时间延迟会导致过度反应和震荡。
- 适用信号：招聘/库存/广告投放的大起大落；"做了没效果就加码"。
- 使用步骤：①估算行动到见效的延迟 ②在延迟期内不要反复加码 ③缩短信息延迟（更快的反馈） ④用小步调整代替大幅波动。
- 常见误区：把延迟误认为无效。

### 冰山模型 Iceberg Model
- 核心：事件 → 模式 → 结构 → 心智模式，越往下越有杠杆。
- 适用信号：问题反复出现；救火式管理。
- 使用步骤：①描述事件（发生了什么） ②找模式（反复出现的趋势） ③找结构（什么制度/激励/流程导致） ④找心智模式（什么信念支撑结构） ⑤在结构或心智层干预。
- 常见误区：停留在事件层"解决"问题。

### 因果回路图 Causal Loop Diagram
- 核心：用图把变量间的因果关系和回路画出来，让隐性结构可视化。
- 适用信号：多因素纠缠；需要向他人解释系统动态。
- 使用步骤：①选 5–10 个关键变量 ②画箭头标 +/− ③标出回路类型和延迟 ④讲出系统的"故事" ⑤用图找干预点。
- 常见误区：变量过多变成意大利面图。

### 系统基模：饮鸩止渴 Fixes That Fail
- 核心：快速修复缓解症状，但带来延迟的副作用使问题更糟。
- 适用信号：打折促销、加班赶工、借债填坑反复出现。
- 使用步骤：①识别快速修复 ②追踪它的延迟副作用 ③量化长期代价 ④寻找根本方案，必要时短期修复与长期方案并行。
- 常见误区：完全拒绝短期修复。

### 系统基模：转移负担 Shifting the Burden
- 核心：依赖症状解法，根本解法的能力逐渐萎缩（成瘾结构）。
- 适用信号：依赖外包/顾问/某个超级员工；依赖投放而非产品。
- 使用步骤：①区分症状解与根本解 ②发现根本能力在萎缩 ③逐步把资源转向根本解 ④设定依赖度下降的指标。
- 常见误区：突然切断症状解导致崩溃。

### 系统基模：增长上限 Limits to Growth
- 核心：增强回路驱动增长，终会触发调节回路（资源、市场、管理能力）。
- 适用信号：增长放缓、更努力也没用。
- 使用步骤：①识别增长引擎 ②找出正在显现的限制因素 ③去除限制而不是更用力推增长 ④提前预判下一个限制。
- 常见误区：在限制处加大油门。

### 系统基模：公地悲剧 Tragedy of the Commons
- 核心：个体理性地过度使用共享资源，导致资源枯竭。
- 适用信号：共享预算、公共渠道、平台流量、团队公共时间被滥用。
- 使用步骤：①识别共享资源和使用者 ②让使用成本可见 ③建立配额、定价或产权 ④设反馈机制。
- 常见误区：只靠道德呼吁。

### 系统基模：富者愈富 Success to the Successful
- 核心：先获得资源的一方因表现更好获得更多资源，另一方被饿死。
- 适用信号：资源分配、新老业务竞争、马太效应。
- 使用步骤：①识别分配规则 ②判断差距是能力还是初始资源造成 ③为新项目设独立保护预算 ④定期重新评估。
- 常见误区：把马太效应结果当作能力证明。

### 系统基模：恶性升级 Escalation
- 核心：双方以对方行为为威胁，不断加码。
- 适用信号：价格战、军备竞赛、争吵升级、补贴大战。
- 使用步骤：①识别双方各自的"安全目标" ②发现相互引用 ③单方面降级或建立沟通 ④改变比较基准。
- 常见误区：认为只有赢下升级才能结束。

### 稳态 Homeostasis
- 核心：系统会抵抗改变，回到原有平衡（组织惰性、习惯回弹）。
- 适用信号：变革推不动；改了又回去。
- 使用步骤：①找出维持现状的调节机制 ②改变设定值（目标、标准）而不只是推动 ③为新状态建立新的调节回路。
- 常见误区：靠一次性冲击改变。

### 非线性 Nonlinearity
- 核心：投入与产出不成比例，存在阈值、临界点、边际递减。
- 适用信号：小变化引发大结果或大投入无效果。
- 使用步骤：①画投入-产出曲线 ②找阈值和饱和点 ③在陡峭区加码、在平坦区停手。
- 常见误区：线性外推。

### 复杂适应系统 Complex Adaptive Systems
- 核心：由会学习和适应的主体组成，干预会被系统"学习并反制"。
- 适用信号：市场、生态、社区、组织政策。
- 使用步骤：①识别主体和其适应规则 ②预测主体对干预的反应 ③小规模多实验 ④放大有效的、关停无效的。
- 常见误区：用一次性大规划控制。

### Cynefin 框架
- 核心：按问题性质分五域：清晰（最佳实践）、繁杂（专家分析）、复杂（探索-感知-响应）、混乱（先行动稳定）、失序（先判断属于哪域）。
- 适用信号：不确定该用什么方法应对问题时（元框架）。
- 使用步骤：①判断因果关系是否明显/可分析/仅事后可知/无关联 ②归入对应域 ③用对应策略：清晰→照章办；繁杂→请专家；复杂→小实验；混乱→立刻止血。
- 常见误区：用繁杂域方法（详细规划）处理复杂域问题。

### 网络效应 Network Effects
- 核心：每增加一个用户，产品对所有用户的价值上升。
- 适用信号：平台、社区、社交产品、协议标准。
- 使用步骤：①判断类型：直接/双边/数据/社交 ②找到临界规模 ③设计冷启动（单一垂直场景、补贴一边） ④评估网络强度与反向网络效应（拥堵、质量下降）。
- 常见误区：把普通增长当成网络效应。
