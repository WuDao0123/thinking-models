# 路由表：问题类型 → 思维模型

用法：
1. 在"问题类型识别表"中按信号词和问题意图匹配 1 个主类型（最多 2 个副类型）。
2. 到对应小节取"首选组合"，按需从"备选"替换或补充。
3. 模型名后的编号即模型库文件（如 `[03]` = `03-decision.md`），去该文件读取使用步骤。
4. 每次都可追加一个 `[05]` 认知偏差做防错自检（选与问题最相关的 1–3 个偏差）。

## 二、各类型推荐组合

### T1 二选一 / 多选一决策
- 首选：`可逆/不可逆决策`[03] → `决策矩阵`[03] 或 `期望值`[03] → `机会成本`[03]
- 备选：`WRAP 决策法`[03]（防窄框）、`满意化 vs 最大化`[03]（低重要性）、`信息价值`[03]（是否需要再调研）、`10/10/10 法则`[03]
- 防错：`确认偏差`[05]、`现状偏差`[05]、`框架效应`[05]

### T2 重大人生 / 职业抉择
- 首选：`可逆/不可逆决策`[03] → `后悔最小化`[03] → `杠铃策略`[16] → `事前验尸`[03]
- 备选：`代理决策：替代判断与最佳利益`[22]（替家人做重大决定时）、`共享决策与严肃疾病沟通`[17]（涉及重病/医疗/照护决策时优先）、`个人财务跑道`[16]（涉及辞职/脱产/创业时必用）、`生之意义`[22]、`可承受损失原则`[16]、`最危险假设优先`[09]、`止损`[16]、`约束理论 / 瓶颈`[02]、`能力圈`[01]、`期权思维`[16]、`悼词法`[22]、`探索与利用`[21]
- 防错：`情感预测偏差与后悔的时间不对称`[05]、`沉没成本`[03]、`损失厌恶`[05]、`从众效应`[05]、`乐观偏差`[05]

- 注意：涉及重病、医疗、照护或临终决策时，以 `共享决策与严肃疾病沟通`[17] 为主轴，明确划分"思维模型能帮什么 / 必须由医疗团队判断什么"，最终选择属于当事人。
- 注意：涉及子女、学生、下属或被照护者的决策时，同时考虑对方的自主权与发展阶段，可用 `渐进式自主 / 支架式放权`[11] 与对方共同制定规则、底线与扩权/回收条件。
### T3 原因诊断
- 首选：`竞争假设分析`[13]（涉及"是谁/是什么造成的"且多种解释并存、或有声誉与利益冲突时优先）；或 `指标拆解树`[13]（问题涉及数字指标时优先）或 `5 个为什么`[13] → `鱼骨图`[13] / `凯普纳-特里戈法`[13] → `假设驱动`[13]
- 注意：用户转述了他人的方案时，先诊断，再检验方案是否作用于瓶颈因子。
- 备选：`实验设计与可重复性`[13]（需要通过实验分清原因时）、`凯普纳-特里戈法`[13]（是/不是对比）、`冰山模型`[02]、`激励`[06]（行为异常时先看激励）、`汉隆剃刀`[01]（人的问题）、`二分法排查`[13]
- 防错：`基本归因错误`[05]、`叙事谬误`[05]、`相关不等于因果`[04]

### T4 反复出现 / 越治越糟的问题
- 首选：`冰山模型`[02] → `反馈回路`[02] → `杠杆点`[02]
- 备选：`系统基模：饮鸩止渴`[02]、`系统基模：转移负担`[02]、`系统基模：增长上限`[02]、`稳态`[02]、`延迟`[02]、`根因分析`[13]
- 防错：`结果偏差`[05]、`计划延续偏差`[05]

### T5 复杂问题无从下手
- 首选：`Cynefin 框架`[02]（先判断问题性质）→ `议题树 / 逻辑树`[13] → `主要矛盾`[22]
- 备选：`MECE 原则`[13]、`问题重构`[13]、`分而治之`[13]、`帕累托分析`[13]、`波利亚四步法`[13]
- 防错：`所见即全部`[05]

### T6 预测与判断可能性
- 首选：`基础比率`[04] → `贝叶斯更新`[01] → `概率思维`[01]
- 备选：`校准`[01]、`置信区间`[04]、`联合概率`[21]（多步骤计划）、`S 曲线`[21]、`情景规划`[16]
- 防错：`过度自信`[05]、`规划谬误`[05]、`可得性启发`[05]、`叙事谬误`[05]

### T7 评估数据 / 证据 / 说法
- 首选：`竞争假设分析`[13]（需要在多个解释间判断时）；`逻辑谬误清单`[17]（先拆"前提→结论"，区分预测与推论）+ `可证伪性`[01] → `证据层级`[01] + `基础比率`[04] → `相关不等于因果`[04] / `幸存者偏差`[04]（按证据类型选）
- 备选：`结构化评估与噪声控制`[19]（评分、评审、面试结果是否可信）、`偏差正常化与事故前兆`[16]（用"无事故"作证据时）、`实验设计与可重复性`[13]（实验/科研/A-B 测试类证据）、`选择偏差`[04]、`辛普森悖论`[04]、`样本量与统计显著性`[04]、`多重比较问题`[04]、`均值、中位数与众数`[04]、`可证伪性`[01]、`风险共担`[16]（谁在说、利益如何）
- 防错：`确认偏差`[05]、`权威偏差`[05]、`光环效应`[05]

### T8 风险评估与抗风险设计
- 首选：`事件指挥与危机响应`[19]（风险已经发生时）或 `避免毁灭`[16] → `事前验尸`[03] → `反脆弱`[16] 或 `杠铃策略`[16]
- 备选：`供应链韧性与安全库存`[16]（采购与供应风险）、`偏差正常化与事故前兆`[16]、`运行设计域 / 适用边界`[16]、`适应性路径 / 稳健决策`[16]（长期深度不确定）、`压力测试`[16]、`遍历性`[04]、`肥尾`[04]、`黑天鹅`[16]、`安全边际`[03]、`冗余`[16]、`瑞士奶酪模型`[16]、`失效模式与影响分析`[16]、`风险 vs 不确定性`[16]、`止损`[16]
- 防错：`乐观偏差`[05]、`零风险偏差`[05]

### T9 商业模式 / 行业分析
- 首选：`波特五力`[08] → `商业模式画布`[08] → `单位经济 LTV / CAC`[09]
- 备选：`供应链韧性与安全库存`[16]、`全生命周期成本`[06]、`价值链`[08]、`PESTEL 分析`[08]、`聚合理论`[08]、`沃德利地图`[08]、`交易成本`[06]、`规模经济`[06]、`供给与需求`[06]、`创造性破坏`[06]
- 防错：`幸存者偏差`[04]、`从众效应`[05]

### T10 竞争策略 / 护城河
- 首选：`7 种力量`[08] → `护城河`[08] → `反定位`[08]
- 备选：`颠覆式创新`[08]、`蓝海战略`[08]、`生态位`[20]、`战略即取舍`[08]、`好战略的内核`[08]、`知己知彼`[22]、`红皇后效应`[20]、`先发优势 vs 后发优势`[07]
- 防错：`过度自信`[05]、`宜家效应`[05]

### T11 创业起步 / 需求验证
- 首选：`最危险假设优先`[09] → `妈妈测试`[09] → `精益创业 / MVP`[09]
- 备选：`数据主权与集体授权`[22]（产品依赖他人数据时）、`实验设计与可重复性`[13]、`使用者-购买者分离`[09]、`待完成的工作`[08]、`从后往前做`[09]、`做不可规模化的事`[09]、`可承受损失原则`[16]、`产品市场契合`[09]、`1000 个铁杆粉丝`[09]、`默认存活`[09]、`费米估算`[04]
- 防错：`虚假共识效应`[05]、`宜家效应`[05]、`确认偏差`[05]
- 注意：涉及健康、安全、金融或弱势群体（老人、儿童、病人）的产品，必须加 `失效模式与影响分析`[16]，并检查知情同意、隐私（健康/儿童数据属敏感信息）与监管合规（先检索，标注是否有确定结论）。

### T12 产品规划 / 优先级
- 首选：`待完成的工作`[08] → `RICE 优先级`[09] 或 `卡诺模型`[09] → `MoSCoW 法`[09]
- 备选：`使用者-购买者分离`[09]、`用户故事地图`[09]、`价值主张画布`[09]、`帕累托法则`[15]、`约束理论 / 瓶颈`[02]、`福格行为模型 B=MAP`[10]（目标用户操作能力有限时）
- 防错：`宜家效应`[05]、`知识的诅咒`[05]
- 注意：涉及健康、安全、金融或弱势群体的产品，安全类功能（防误用、静默失效告警）应列为 Must，并用 `失效模式与影响分析`[16] 检查。

### T13 增长 / 留存 / 转化
- 首选：`指标拆解树`[13] 或 `AARRR 海盗指标`[09] → `留存曲线`[09] → `福格行为模型 B=MAP`[10]
- 备选：`成功指标与护栏指标体系`[09]（实验与上线决策）、`实验设计与可重复性`[13]（A/B 测试）、`北极星指标`[09]、`激活时刻`[09]、`上瘾模型`[09]、`存量与流量`[02]、`飞轮效应`[08]、`病毒系数 K-Factor`[10]、`精准渠道匹配`[10]、`摩擦`[20]、`跨越鸿沟`[09]、`网络效应`[02]
- 防错：`古德哈特定律`[06]、`噪声与信号`[04]

### T13b 内容 / 社媒账号增长
- 首选：`费米估算`[04] + `幂律`[21]（目标需要多少曝光、是否现实）→ `存量与流量`[02] + `约束理论 / 瓶颈`[02]（曝光→主页访问→关注漏斗，瓶颈随阶段移动）→ `探索与利用`[21]（先测形式再集中）
- 备选：`成功指标与护栏指标体系`[09]、`个人垄断`[22]、`定位理论`[10]（转化瓶颈时）、`内容飞轮`[10]、`共振`[20]、`钩子-故事-报价`[10]、`让创意更有粘性`[10]、`1000 个铁杆粉丝`[09]、`复利`[21]、`S 曲线`[21]、`重复博弈`[07]（与同赛道账号互动）
- 防错：`古德哈特定律`[06]（为数字牺牲粉丝质量）、`幸存者偏差`[04]（涨粉打法案例）、`系统基模：转移负担`[02]（AI 批量回复/内容）、`噪声与信号`[04]
- 注意：平台算法与规则会变，推演前先检索当前机制，并标注来源可信度（官方 / 第三方解读）。

### T14 定价
- 首选：`价格弹性`[06] → `价格锚点与定价心理`[10] → `单位经济 LTV / CAC`[09]
- 备选：`供给与需求`[06]、`信号理论`[06]、`谢林点`[07]、`边际成本为零`[21]、`稀缺性`[06]、`诱饵效应`[05]、`体验经济`[10]
- 防错：`锚定效应`[05]、`损失厌恶`[05]

### T15 定位 / 品牌 / 个人 IP
- 首选：`定位理论`[10] → `个人垄断`[22] → `品类设计`[10]
- 备选：`STP 市场细分-目标-定位`[10]、`黄金圈`[10]、`生态位`[20]、`技能叠加`[12]、`刺猬理念`[08]、`心智份额`[10]、`信号理论`[06]、`1000 个铁杆粉丝`[09]
- 防错：`虚假共识效应`[05]、`知识的诅咒`[05]

### T16 内容创作 / 营销文案
- 首选：`受众分析`[17] → `让创意更有粘性`[10] → `AIDA 模型`[10] 或 `钩子-故事-报价`[10]
- 备选：`PAS 文案公式`[10]、`英雄之旅`[10]、`品牌故事框架`[10]、`内容飞轮`[10]、`西奥迪尼影响力六原则`[10]、`共振`[20]、`具体化原则`[17]、`峰终定律`[11]、`幂律`[21]
- 防错：`知识的诅咒`[05]、`近因效应`[05]

### T17 创新 / 想点子
- 首选：`第一性原理`[01] → `SCAMPER 奔驰法`[14] → `组合创新`[14]
- 备选：`我们可以如何`[14]、`水平思考`[14]、`逆向头脑风暴`[14]、`形态分析法`[14]、`相邻可能`[14]、`约束激发创意`[14]、`TRIZ 发明问题解决理论`[13]、`十倍思维`[14]、`设计思维`[14]、`美第奇效应`[14]

- 备选：`数据主权与集体授权`[22]（涉及社区、用户或员工数据时）、`结构化评估与噪声控制`[19]（涉及选拔或评审人员时）、`竞争假设分析`[13]（调查或事故定性）、`成功指标与护栏指标体系`[09]（算法、产品或政策上线）、`供应链韧性与安全库存`[16]（供应中断或扩张导致的供应压力）、`偏差正常化与事故前兆`[16]、`运行设计域 / 适用边界`[16]（试点推广、技术系统扩张）、`全生命周期成本`[06]（基建或长期运营项目）、`代表性公众参与与协商`[17]（公共或社区决策）、`代理决策：替代判断与最佳利益`[22]（涉及逝者、失能者或子女时）、`实验设计与可重复性`[13]（科研或技术路线抉择）、`公平与分配原则`[22]（涉及谁受益谁承担代价时必用）、`指标拆解树`[13]（先诊断致因再比较方案）、`外部性`[06]（风险转移给第三方）、`最危险假设优先`[09]（新业务）、`情景规划`[16]、`杠铃策略`[16]、`止损`[16]（触发条件）、`事前验尸`[03]、`客观标准`[18]、`DACI 决策框架`[19]、`不同意但执行`[19]、`关键对话`[17]、`心理安全感`[19]、`指标拆解树`[13]、`使用者-购买者分离`[09]、`赢家诅咒`[07]
- 防错：`沉没成本`[03]、`承诺升级`[05]、`乐观偏差`[05]、`群体思维`[05]、`基本归因错误`[05]
- 固定输出模板：①基线测算 ②路径对比（现金情景表 + 优势/风险/可逆性表，并标注模型盲区）③推荐（通常是组合路径而非单选）④时间表 ⑤信息缺口（按是否改变决策排序）⑥验证与现金预算（保留现金底线）⑦改变推荐的触发条件 ⑧决策者分歧处理 ⑨团队/利益相关方沟通 ⑩不确定性。
- 注意：路径往往不互斥，先检查能否组合；涉及裁员、收购、合同时注明需律师/财务顾问；对交易对手须如实披露重大不利信息。

- 注意：家庭版（子女教育、赡养、家族资产）同样适用本模板；涉及子女时加 `渐进式自主 / 支架式放权`[11] 与 `可证伪性`[01]（各方写下"什么证据会让我改变想法"）。
