# thinking-models：思维模型路由器

将问题对应到适用的思维模型，帮助 AI 分析、判断、规划和决策。

## 能做什么

- 覆盖 22 类模型参考资料，包括系统、决策、概率、经济、战略、学习、沟通和人生选择等。
- 识别问题类型，选择最适用的 2–4 个模型。
- 按模型的使用步骤分析，给出结论、行动建议和不确定性。
- 简单问题使用较少模型，避免为了展示模型而堆砌概念。

模型目录及具体规则见 [SKILL.md](SKILL.md) 和 [路由参考](references/routing.md)。模型数量是内容分类口径，不代表独立、互不重叠的科学理论数量。

## 安装

下载本仓库 ZIP 并解压，将包含 `SKILL.md` 和 `references/` 的整个文件夹命名为 `thinking-models`，放入所用 AI 工具的 Skills 目录。

Codex 本地安装可放入 `~/.codex/skills/thinking-models/`。保留以下结构：

```text
thinking-models/
├── SKILL.md
└── references/
    ├── routing.md
    └── 01-meta-thinking.md … 22-life-philosophy.md
```

安装后重启或重新加载工具，确认 Skill 已被识别。其他支持 Skills 的工具请按其安装规则操作。

## 使用示例

在支持显式调用 Skill 的工具中选择 `thinking-models`，然后提问，例如：

- 如何使用 AI 创造最大价值？
- 如何在三个月内验证一个产品，并实现明确的经营利润目标？
- 面对海外工作、留任和无薪假，我该如何比较家庭得失并做决定？

在 Codex 中也可输入：

```text
$thinking-models 请分析这个问题：……
```

提供目标、时间限制、预算、已知事实和不能接受的结果，通常能得到更具体的分析。

## 使用边界

这是分析辅助工具。模型选择、估计和建议需要结合真实数据检验；涉及变化中的事实应核实来源。重大决定仍需结合当事人的判断，专业问题应核对相应专业意见。
